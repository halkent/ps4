# Halkent PS4

https://halkent.github.io/ps4/

Halkent arayüzü; 1352, 1400, 1300, css, 900, 700, 672 ve 505 host dosyaları yerel olarak sunulur.

Kaynak değişiklikleri: arayüz markası, renkler, ana menü, yerel bağlantılar ve önbellek manifestleri. Exploit kodları ve ikili payload dosyaları değiştirilmedi.

Kaynak ve lisans bildirimleri upstream-notices/ ve 1400/LICENSE dosyalarında korunmuştur. Konsol üzerinde çalışma ve çevrimdışı önbellek ayrıca donanım testi gerektirir.
