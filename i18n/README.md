# Halkent arayüz dilleri
Türkçe kaynak metinler esas alınır. Diğer dil dosyaları otomatik çeviriyle hazırlanmıştır; teknik tanı günlükleri değiştirilmez. Çeviri hizmeti kullanıcı tarayıcısında çalıştırılmaz. Seçilen sözlük yerel dosyadan yüklenir ve çevrimdışı önbelleğe dahildir.
Dil listesi DualShock Tools dil menüsüyle eşleştirildi: https://github.com/dualshock-tools/dualshock-tools.github.io/blob/main/js/translations.js
Tercih halkent.language anahtarında saklanır. app.halkent.com ve halkent.github.io/ps4 geçişlerinde lang parametresiyle aktarılır.
